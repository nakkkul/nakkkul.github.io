# Nakul Kumar — Portfolio Website

A responsive, static portfolio for projects in data science, machine learning, NLP, and AI-powered applications.

## Preview locally

This site uses plain HTML, CSS, and JavaScript. No build step or package installation is required.

1. Clone or download this repository.
2. Open \`index.html\` in a browser, or serve the folder with a small local static server.
3. Use the desktop and mobile layouts to check the navigation, project links, certificate links, and résumé download.

## Main sections

- Introduction and résumé download
- Two featured projects: QnA Chatbot and Phishing Website Detection
- About and professional experience
- Skills grouped by project use
- Additional projects, education, and selected certificates
- Contact links

## Technologies shown

Python, pandas, NumPy, SQL/MySQL, scikit-learn, TensorFlow/Keras, LangChain, Hugging Face, Groq, Sentence Transformers, FAISS, Streamlit, FastAPI, HTML/CSS, Git/GitHub, Docker, GitHub Actions, and Render.

The site uses the existing GitHub Pages static-hosting approach. It does not need a frontend framework or a build pipeline.

## Updating the content

- Edit project text and links in \`index.html\`.
- Visual styles and responsive breakpoints are in \`css/style.css\`.
- Mobile navigation and small progressive enhancements are in \`js/script.js\`.
- The résumé PDF is \`Nakul Kumar.pdf\`.
- Existing portraits and certificate images remain in \`assets/images/\`.

## Verification checklist

Before merging to \`main\`:

- Check the page at mobile widths around 320–390 px, a tablet width, and a desktop width.
- Confirm there is no horizontal overflow and no overlapping text, controls, or cards.
- Test the mobile menu using touch, keyboard, and the Escape key.
- Open both featured demo links and their GitHub repositories.
- Test the résumé download and all certificate links.
- Confirm every image loads, has appropriate alternative text, and doesn't distort its card.
- Search the rendered page and repository content for claims or technologies that aren't supported by the résumé or project repositories.
